# Customer Segmentation using K-Means Clustering

## Internship Task
This project is completed as **Task 3** of the **Data Science Internship at Interncred**.

## Problem Statement
Segment customers into different groups based on their age, annual income, and spending score using clustering techniques.

## Dataset
Mall Customers Dataset from Kaggle.

## Approach
- Selected relevant numerical features
- Applied feature scaling using StandardScaler
- Determined optimal number of clusters using the Elbow Method
- Performed customer segmentation using K-Means clustering
- Visualized customer groups using scatter plots

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Output
Customers were grouped into five distinct segments based on spending behavior
and income levels.

## Conclusion
This project demonstrates how unsupervised learning techniques like clustering
can be used to analyze customer behavior and support business decision-making.
